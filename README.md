# skillshare-source

The installed state of my agent toolkit: the [skillshare](https://github.com/runkids/skillshare)
source folder (`~/.config/skillshare`) with every skill, `mcp.yaml`, `plugins.txt` and
`bootstrap.sh`. Written by `skillshare` and agent-toolkit's `scripts/apply.py`; don't edit by hand.

What to install, why, and the new-machine steps live in
[agent-toolkit](https://github.com/Diz312/agent-toolkit#new-machine).
